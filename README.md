# CO658 - Data Structures & Algorithms

## Setup and Running Week Exercises

Make the run script executable:
```bash
chmod +x run.sh
```

Run the script:
```bash
./run.sh
```

The terminal will prompt week number and exercise number:
```bash
Enter WEEK number: 2
Enter EXERCISE number: 5
```

Terminal will output the selected program
